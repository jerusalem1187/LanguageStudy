## 迁移分析

### 能从英语借

同源词规律（英语词尾对应西语词尾）。认识规律后，大量学术词汇不用背：

| 英语 | 西语 | 例 |
|---|---|---|
| -tion | -ción | nation → nación，information → información |
| -ty | -dad | university → universidad，city → ciudad |
| -ly | -mente | rapidly → rápidamente |
| -ous | -oso | famous → famoso |
| -ist / -ism | -ista / -ismo | artist → artista，realism → realismo |
| -ance / -ence | -ancia / -encia | importance → importancia |
| -ble | -ble | possible → posible |
| -ent / -ant | -ente / -ante | different → diferente |

拉丁字母、阿拉伯数字都一样。语法术语（subjunctive、preterite、reflexive）读英文语法书时直接认。

### 能从中文借

词汇上几乎没有。中文和西语都没有格，名词不变格，这一点比俄语省事。

### 要专门建立的概念

| 概念 | 阶段 | 说明 |
|---|---|---|
| 冠词 el / la / los / las / un / una | 第 1–2 周 | 中文英文都不按性分。每个名词和冠词一起记。 |
| 性数一致 | 第 2–4 周 | 形容词跟名词变：casa blanca / casas blancas。 |
| 动词变位 | 第 2 周起，持续到 B2 | 人称 × 时态 × 语气。中文没有，英语只剩残余。这是西语学习的主线。 |
| pretérito 和 imperfecto 的区分 | 第 5–12 周 | 中文靠副词和语境，西语靠动词形态区分「一次完成」和「持续或背景」。 |
| 虚拟式 | A2 末 | 中文英文都没有系统的对应物。 |

## 难点地图

| 难点 | 阶段 | 说明 |
|---|---|---|
| 动词变位 | A0 起持续 | -ar / -er / -ir 三类规则动词先记；不规则动词按出现频率记（ser, estar, tener, ir, hacer, poder, querer, decir）。时态顺序：presente → pretérito indefinido → imperfecto → futuro / condicional → subjuntivo。每个时态用 SpanishDict 的变位表加例句卡。 |
| 重音符号 | A0 起持续 | 拼写的一部分，见「文字与拼写要点」。动词变位里的固定模式先记：-ó（pretérito 第三人称）、-é（第一人称）、-ía（imperfecto 和 condicional）、-á / -ás（futuro）。 |
| 同音异拼 | A0–A1 | b / v、h、ll / y、g / j、c / s / z 这几组在读音上不分或难分，拼写只能按词记。见「文字与拼写要点」。 |
| ser / estar | A1 | 两个「是」。ser 说本质和身份，estar 说状态和位置。靠例句对比记，不靠规则列表。 |
| 性数一致 | A0–A1 | 名词性别多数看词尾（-o 阳，-a 阴），例外单独记（el día, la mano, el problema）。 |
| por / para | A2 | 两个「为了 / 因为」。常见搭配整块记。 |
| 宾语代词与 se | A2–B1 | 直接和间接宾语代词的位置（动词前，或接在不定式和命令式后面）；se 有反身、被动、无人称等多种用法。 |
| 虚拟式 | A2 末到 B1 | 触发结构（quiero que…, es posible que…, cuando + 未来）先记常见的 10 个。 |
| 变体差异 | A1 起 | vosotros（西班牙）与 ustedes（拉美）；拉美文本里没有 vosotros 的变位。读写阶段影响很小。 |

## 文字与拼写要点

拼写和读音几乎一一对应，所以西语的拼写难点集中在重音符号和几组同音字母。

- **字母**：27 个，比英语多 ñ。ch 和 ll 不再算独立字母。
- **重音符号**：不是装饰，是拼写的一部分，漏写算错。规则用来理解，记词时把符号连同词形一起记。
  - 以元音、n、s 结尾的词，重音默认在倒数第二音节；不在默认位置的要标：está、canción、también。
  - 以其他辅音结尾的词，重音默认在最后一音节；不在默认位置的要标：fácil、árbol、lápiz。
  - 重音在倒数第三音节的一律标：teléfono、médico、rápido、sábado。
  - 区分同形词：sí / si，él / el，tú / tu，mí / mi，más / mas，sé / se，dé / de，té / te。
  - 疑问词和感叹词带符号：qué、quién、dónde、cuándo、cómo、cuánto。
  - -mente 副词保留原形容词的符号：rápido → rápidamente。
- **同音异拼**（当前不学发音，这些组只能按词记）：b / v（haber 与 a ver）；h 不发音（hacer、hora、hombre）；ll / y（llamar、yo）；e / i 前的 g 与 j（gente、jefe）；c / s / z（casa、caza）；qu / c / k（que、casa、kilo）。
- **问号和感叹号**：句首加倒置符号：¿Cómo estás? ¡Hola!
- **大小写**：星期、月份、语言名、国籍形容词小写（lunes、enero、español）。句首和专名大写。
- **数字**：西班牙用逗号作小数点、点作千位分隔（1.000,50），和英语相反。
- **键盘输入**：macOS 上用 US 键盘时，ñ = option + n 再按 n；á é í ó ú = option + e 再按元音；¿ = option + shift + ?；¡ = option + 1。也可以加「西班牙语 - ISO」键盘。iPhone 长按字母出带符号的变体，或加西班牙语键盘。

每日练习（前 4 周）：从教材课文里抄 5 句，第二天看中文默写这 5 句，对照原文标出拼写和重音错误。每天 5 分钟，算进日常课的阅读时间。

## 以后加听说时

当前不用。加听说时先补一个发音周，再接入下面的资源。

- **发音要点**：5 个纯元音；b / v 同音；d 在元音间弱化；r 单闪与 rr 多颤；j 和 e / i 前的 g 读 [x]；ll / y 读 [ʝ]；c（e / i 前）和 z 在西班牙读 [θ]；连读（词尾元音和下一词词首元音合成一个音节）。
- **系统课**：Language Transfer: Complete Spanish（免费音频课，约 90 节，英语讲解）。
- **可理解输入**：Dreaming Spanish（分级视频，superbeginner 起）；Español con Juan、Notes in Spanish、Coffee Break Spanish（播客）。
- **工具**：Forvo（真人发音）；italki、Preply（口语课）。
