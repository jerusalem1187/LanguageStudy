# SRS 页面 v1

只练读写，不含音频、发音和听力练习。页面是一个 HTML 文件，内嵌卡片、进度、样式和原生 JavaScript，没有外部资源、依赖、构建步骤或后台服务。

## 打开

- 更新课程后，先关掉已打开的页面，再重新打开仓库里的 `srs/index.html`，才能加载新课程和新脚本。
- 电脑：在本地克隆目录中双击 `srs/index.html`，用桌面 Chrome 打开。也可用 Edge。直接从 `file://` 打开即可。
- 手机：用 iPhone Safari 打开 GitHub Pages 地址：https://jerusalem1187.github.io/LanguageStudy/srs/index.html 。Pages 已开启，推送 main 后约一分钟更新。本页无需 API 或服务端。
- 每天先复习到期卡，再学额度内的新卡。课程页有讲解、完整词表和各 10 题即时练习；页内练习不计入 SRS。

卡片来自 `cards/es.csv` 和 `cards/ru.csv`，内容与 `index.html` 的 `cards-data` 完全一致。西语 es-01 有 113 条词条，生成 226 张卡；俄语 ru-01 有 33 个字母和 18 个国际词，生成 69 张卡；ru-02 有 14 条／28 张，ru-03 有 36 条／71 张，ru-04 有 40 条／73 张。共 254 条词条／字母、467 张卡；tags 含 `letter` 或 `phrase` 的词条只有识别卡。

课程按语言分组，每课显示周次、日期、目标和本周写作任务；俄语第 1–4 周每天只用 10 分钟，讲解和 10 题分几天完成。

- ru-02（09-21 至 09-27）：练 ЙЦУКЕН 和 macOS“俄语－语音”键位、字母顺序与 14 个国际词，每天打 20 个词。
- ru-03（09-28 至 10-04）：学习拼写规则和常用词，读六句短文并抄写其中 5 句。
- ru-04（10-05 至 10-11）：复习旧词、数字和自我介绍句型，写 5 句自我介绍，周末做月度检查点 1。

ru-03、ru-04 各有六句短文，中文按句默认折叠；3 道阅读理解计入本课 10 题，页内即时判定，不写入 SRS 进度。

## 复习

1. 在“复习”选择 es、ru 或全部。
2. 识别卡：看目标语词条和例句，尝试回忆中文，再翻面。
3. 拼写卡：看中文释义、中文例句和目标语填空，输入词表中的完整词条。西语名词需带冠词，按词表大小写输入。
4. 根据实际记忆情况选择 Again、Hard、Good、Easy。拼写判定只高亮建议，不替你评分。

快捷键：输入框外按空格翻面或提交；拼写输入框按 Enter 提交；翻面后按 1 / 2 / 3 / 4 评分。输入框内的空格用于填写 `por favor` 等短语，不会提前提交。输入法组字时不触发快捷键。手机可用页面按钮。

拼写比较先 trim、NFC 规范化，保留大小写。俄语再忽略 U+0301 重音标记；西语的重音符号必须一致。完全一致建议 Good；去掉变音符后才一致时显示“拼写对了，符号错了”，建议 Hard；其他情况建议 Again。俄语 е / ё、и / й 仍有区别，不能把这些字母上的符号当作可省略的重音。

## 保存

页头常驻“保存”、未保存指示、当前状态来源和最后保存时间。

- 桌面 Chrome / Edge 支持 File System Access API 时，第一次点“保存”务必选中本地仓库里的 `srs/index.html` 并确认替换。之后复用文件句柄直接写入；设置中的“另存为”可以改换位置。选择器使用固定的 `language-srs` id，供 Chrome 记住上次目录；浏览器需要授权时会请求该文件的写入权限。
- 文件句柄存入 IndexedDB，按页面路径区分。若浏览器不允许保留句柄，下次打开会重新选择。设置中的“另存为”可以改换文件位置。
- 不支持该 API 时，点保存会下载一份 `index.html`；设置中的“下载 HTML”也可直接下载。请确认下载完成，必要时手动替换仓库文件。浏览器无法通知页面下载最终是否落盘；界面会注明“下载生成”。
- 每次评分、修改额度、导入后自动缓存状态和卡片。重新打开时比较缓存和文件中的 `updatedAt`，进度取较新者；词条以文件为准，只追加缓存独有的 id，避免旧缓存遮住新课程。同 id 的页内词条修改需要保存到文件后才能在重开时保留。采用较新缓存进度时，会显示“有未保存到文件的进度，记得保存”。
- 有文件句柄时，保存前先读取磁盘文件，比较卡片条数和进度 `updatedAt` 与本页加载时／上次成功写文件后的快照。发现不同会停止写入，提示重新打开页面，并将保存按钮改为“仍要覆盖”；再次点击才覆盖。如果两次点击之间磁盘快照再次变化，会重新提示。新建的空文件可直接保存。
- 写文件时克隆文档并按白名单清理：head 只保留 charset、viewport、srs-saved-at、srs-save-kind 四个 meta、title 和 `#srs-style`；body 只保留空的 `#app`、两个 JSON 块与主脚本 `#srs-app`，并移除 html、body 上外来的属性。更新 JSON 与保存时间后输出完整 HTML，重新打开由脚本渲染。浏览器注入的其他节点不会进入保存文件；JSON 中的结束 script 标签按 `<\/script>` 转义，导入文本按纯文本显示。
- 写文件失败或取消时不会清除未保存标记。写入期间若产生新评分，本次只保存取得快照时的进度，新的修改仍提示待保存。

保存完成后由人工执行 `git add`、`git commit` 和 `git push`。页面不会调用 Git，也不会自动更新 GitHub Pages。

## 手机进度合并

手机上的复习进度只在该手机浏览器的本地缓存中，不会回写 GitHub 或电脑文件。

1. 在手机“设置 → 导出／导入进度”复制进度 JSON，或下载进度 JSON 文件。
2. 把文本或文件传到电脑；在电脑同一页面粘贴导入，或选 JSON 文件导入。
3. 页面按卡片 id 合并：`last` 日期更晚的记录优先；同一天比较该卡日志里的最近评分时间；仍相同则保留电脑当前记录。首次复习日保留两边较早的日期。
4. 合并日志并去除完全重复的记录，仅保留最近 60 个本地日期。本机的每日新卡设置不被手机设置覆盖。
5. 电脑点保存，再人工提交和推送。

导出 JSON 只含进度，不含词条内容。设备间需使用相同卡片；未知 id 的进度会保留但不计入统计，待导入相应 CSV 后使用。如果修改了手机上的卡片内容，也要把对应 CSV 带到电脑导入。

## 加卡片

1. 编辑 `srs/cards/es.csv` 或 `srs/cards/ru.csv`。文件保存为 UTF-8，列顺序固定：

   `id,lang,lesson,front,back,example,example_zh,note,tags`

2. id 是稳定且唯一的字符串，如 `es-0114`；可以用英文字母、数字、点、下划线、连字符，以字母或数字开头。不复用旧 id 表示另一个词，不给已有 id 更换语言。lang 为 es / ru，lesson 形如 es-01 / ru-02。
3. 名词在 note 按课内规则标性；俄语词条把 U+0301 放在重读元音后，普通单音节词可不另标。`note`、`tags` 可空，tags 用分号隔开。字母卡用 `letter`，整句短语用 `phrase`；两种标签都只生成识别卡。
4. 词条、释义、目标语例句、中文例句不可空。例句尽量含有完整 front；挖空会忽略句首大小写、俄语重音标记，并检查词边界。若找不到完整词条，拼写正面会隐藏目标语原例句，只按中文要求填写；翻面才显示原例句。
5. 字段含逗号、双引号或换行时，外层加双引号，内部双引号写成两个双引号。表头不可省略；支持 BOM 和 CRLF 换行。
6. 到“设置 → 导入卡片 CSV”选文件，或粘贴 CSV 后点击导入。按 id 合并，新 id 增加，旧 id 更新内容，状态保留。不删除 CSV 未列出的卡片。
7. 点保存，使页面内嵌数据与 CSV 保持一致，再人工提交两者。只改 CSV 不会自动改变已打开或已保存的页面；只在页面导入不会反向修改 CSV 来源文件。

所有导入先完整检查，通过后才修改当前数据。每个选取的文件最多 20 MB，最多 50000 条词条。导入其他课次的词条可参与 SRS；课程讲解和页内练习由 `LESSONS` 注册表提供，目前有 es-01、ru-01 至 ru-04。每条记录包含 name、lang、week、dates、goal、writingTask、explanation、reading、exercises；explanation 是返回 HTML 的函数，reading 可空，阅读题同时列入本课 exercises。

## 算法与统计口径

- 评分对应 SM-2：Again = 0、Hard = 3、Good = 4、Easy = 5。初始 ease 为 2.5，下限 1.3；按 SM-2 公式更新 ease。
- 首次成功及 Again 重置后的首次成功：Hard / Good 为 1 天，Easy 为 4 天。第二次连续成功为 6 天；之后为“原间隔 × 本次更新前的 ease”，四舍五入到整天。这是 SM-2 加任务指定的首次 Easy 4 天规则，不另加 Hard 倍率。
- Again：reps 归零，lapses 加一，间隔为 0、到期日为今天，加入本次会话末尾的重学队列。重复 Again 会再次排到末尾。重开页面后仍作为到期卡出现。
- 今天和日期加减按设备的本地日历计算，不用 UTC 日期切片。到期卡包含逾期卡。注意两台设备应设为相同的日期与时区；日志时间使用 ISO 时间。
- 每日新卡默认 es 15、ru 10；识别和拼写分别计数。同一词条的拼写卡在识别卡第一次评分的次日才可引入，之后也受每日额度限制。按课次、id 的自然顺序引入，先处理到期卡；0 暂停该语言的新卡。
- 每条已复习状态在所给 v1 字段外保留一个可选 `first`（本地首次复习日期）。它用于跨天、刷新后计算每日新卡额度，以及在日志清理后仍正确开放拼写卡。导入不带 `first` 的旧格式时，用该卡现存最早日志日期，缺少日志时用 `last` 补足；若旧日志已丢失，真实首次日期无法完全恢复，拼写卡可能晚一天开放。
- 统计按卡片方向分别计数。新卡包括尚未开放的拼写卡；已复习且间隔小于 21 天为学习中，至少 21 天为已掌握。最近 30 天含今天，统计所有评分次数，非 Again 算对；没有评分时正确率显示“—”。

俄语重音采用常见标准词形，使用了有把握的词。本次按任务限制未联网核对 OpenRussian / Wiktionary，不把离线编写称为词典核验。ru-02 的 macOS 键位已用本机系统自带布局数据离线核对，表格按美式实体键标注；其他系统的语音布局或 ISO 键盘可能不同。字母表用系统衬线字体的真实斜体；不同设备的字体与手写体会有差异。

## 离线验证

已有 Node 时，在仓库根目录运行 `node srs/verify.cjs`。测试只使用 Node 内置模块，不安装依赖，也不起服务。测试自建空状态夹具，真实嵌入进度单独校验；覆盖 CSV 与内嵌数据一致性、课程注册与全部练习判定、卡片方向、日程与新卡额度、拼写、合并、日志窗口、保存白名单往返、缓存选择、外部修改检测和文件读写失败等。可用 `TZ=America/Los_Angeles node srs/verify.cjs` 检查含夏令时的日期环境。

改课时，开工前把 `#state-data` 内的原始字节复制到 `/tmp`，收工运行 `node srs/verify.cjs --state-backup /tmp/留底文件`，额外验证逐字节一致；这项检查不重新序列化 JSON。此次留底为 `/tmp/language-srs-state-data-20260907.bin`。日常复习保存会正常更新进度，之后运行普通验证即可，不应继续拿旧进度留底比较。

保存测试使用最小文档模型和文件 API 模拟，不能替代真实文件选择器、IndexedDB 持久化或手机浏览器测试。本次未完成 Chrome / iPhone Safari 实机验证。

## 已知边界与冻结

本地缓存按浏览器和页面路径区分；`file://` 的存储行为由浏览器决定。清理浏览器数据、隐私模式、换浏览器或换路径可能使缓存或句柄不可用，请以保存的 HTML / 导出的 JSON 为备份。不要同时在多个标签页复习同一路径；页面会提示其他标签页更新，但不会自动合并并发评分。课程更新后重新打开页面，新文件里的词条会保留，较新的本地缓存只优先提供进度。

外部修改检测按本次约定只比较卡片条数与 `updatedAt`：同条数、同时间戳的内容修改无法发现；检测到写入之间也没有跨进程原子锁。下载 HTML 无文件句柄，无法检测或直接保护原文件。

v1 到 **2026-12-06 复盘前只修 bug，不加功能**。先按现有页面学习，再在复盘时决定是否调整。
