# 任务 M2：马来语 ms-05 至 ms-08（第 5–8 周）与阅读线 ms-r07 至 ms-r14

先完整读 `malay/tasks/00-common.md`，再读本文件。前提：M1 已合并。本轮起 dailyTime 为「每天 20 分钟 + 每周 1 次系统块 30 分钟」。每课 80 条、6 + 4 题、课内阅读 80–120 词 10–14 句。

## 课程

### ms-05 · ber- 动词与日常活动（第 5 周，11-02 至 11-08）

- 讲解：ber- 构成不及物动词和「有、穿、用」义（berjalan、berlari、bermain、bercakap、berbual、berkata、berdiri、berhenti、bertemu、bekerja、belajar、berenang、berbaju、berkereta）；变体 be-（r 开头词根、kerja）、bel-（ajar）；ber- + 名词表「有、乘、穿」；第 1–4 周的光杆动词哪些在书面语里要加词缀（belajar、bekerja 已是 ber- 形）；频率副词 selalu、sentiasa、biasanya、kadang-kadang、jarang、tidak pernah、setiap hari；11-08 月度检查点 2。写作：5 句「我每天做什么」。
- 词表：ber- 动词 25（note 写词根和变体）、频率与时间副词 8、活动与运动名词 15、身体与衣物 10、整句 5、借词与补充至 80。
- 课内阅读：日常生活。

### ms-06 · meN- 前缀（第 6 周，11-09 至 11-15）

- 讲解：meN- 构成及物动词，五条变形规则各一个 `<h4>`：me-（l、m、n、ng、ny、r、w、y：melihat、memasak、menanti、merasa）；mem-（b、f、v 及 p 脱落：membaca、membeli、memakai、memukul）；men-（c、d、j、sy、z 及 t 脱落：mencari、mendengar、menjual、menulis、menunggu）；meng-（元音、g、gh、h 及 k 脱落：mengambil、mengajar、menghantar、mengira、mengirim）；meny-（s 脱落：menyapu、menyewa、menyanyi）；menge-（单音节词根：mengecat、mengebom）；借词辅音簇保留（memproses、mengkaji、mentadbir）。及物动词 + 宾语；口语里 makan、minum 常不加前缀；第 2–4 周的光杆动词换成 meN- 形写正式句（baca → membaca，tulis → menulis，beli → membeli）。写作：5 句含 meN- 动词，每条规则至少一句。自查表：按规则编号核对首字母。
- 词表：meN- 动词 35（note：「meN- + tulis → menulis，t 脱落」，覆盖六种变形各至少 4 个）、宾语名词 20、连词与副词 5、整句 5、补充至 80。
- 课内阅读：短故事。

### ms-07 · 介词与方位；问路（第 7 周，11-16 至 11-22）

- 讲解：di（在）、ke（到）、dari（从，地点和时间）；daripada（从某人、由材料、比较）与 dari 的分工；kepada（对某人）、pada（在时间、在抽象对象）、untuk / bagi（为）、dengan（和、用）、tentang / mengenai（关于）、oleh（由）、sejak、hingga / sehingga / sampai、antara、tanpa、seperti；方位词 di atas / bawah / dalam / luar / depan / belakang / sebelah / tepi / tengah / antara；问路对话套语：Di mana …? / Bagaimana hendak ke …? / Jalan terus / belok kiri / kanan / berhampiran。写作：5 句「在哪里、去哪里、和谁、为谁」。
- 词表：介词 16、方位词 12、城市地点 20（stesen、pejabat pos、pasar、kedai、masjid、taman、jalan、jambatan、lapangan terbang、universiti、perpustakaan、klinik…）、交通 8、指路动词与短语 8（`phrase`）、补充至 80。
- 课内阅读：对话（问路）。

### ms-08 · 助动词与情态；请求与禁止（第 8 周，11-23 至 11-29）

- 讲解：boleh（可以、能）、dapat（能够）、mesti / harus / perlu（必须、应该、需要）、mahu / hendak / ingin（想要，书面用 mahu / hendak，ingin 更正式）、suka、tahu、pandai + 动词；助动词与时间标记的顺序（sudah boleh、akan dapat）；请求：tolong + 动词（请帮忙做）、sila + 动词（请、邀请）、minta + 名词；禁止 jangan；-lah 软化（Silalah duduk.）；回答 boleh / tidak boleh / belum boleh。写作：5 句请求和计划。
- 词表：助动词与情态 12、请求与礼貌用语 10（`phrase` 视情况）、日常需求名词 20（食物、饮料、餐馆、商店）、动词 20（含 meN- 形）、整句 5、补充至 80。
- 课内阅读：短信或便条（请求）。
