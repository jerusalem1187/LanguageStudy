# 任务 M3：马来语 ms-09 至 ms-12（第 9–12 周）与阅读线 ms-r15 至 ms-r22

先完整读 `malay/tasks/00-common.md`，再读本文件。前提：M2 已合并。dailyTime「每天 20 分钟 + 每周 1 次系统块 30 分钟」；第 10 周起讲解开头加「时间分配以复盘结果为准」。ms-09 至 ms-11 各 80 条，ms-12 为 40 条；6 + 4 题；课内阅读 120–170 词 12–16 句。

## 课程

### ms-09 · 后缀 -kan：使役与受益（第 9 周，11-30 至 12-06）

- 讲解：-kan 使不及物变及物或使役（besar → membesarkan，jalan → menjalankan，masuk → memasukkan）；受益（beli → membelikan 替某人买，buat → membuatkan）；带 -kan 的常用动词整词记（memberikan、mengatakan、menggunakan、menyediakan、menjelaskan、menyebabkan、mendapatkan、meletakkan）；meN-…-kan 的拼写（词根末尾 k 加 -kan 写 kk：memasukkan）；12-06 月度检查点 3 与探索期复盘，本课末给「探索段自测」：限时写作 50 词。
- 词表：-kan 动词 30、名词 25、副词与连词 5、整句 5、补充至 80。
- 课内阅读：短故事。

### ms-10 · 后缀 -i；-kan 与 -i 对比（第 10 周，12-07 至 12-13）

- 讲解：-i 表处所、方向、反复或以宾语为对象（mengunjungi、memasuki、menaiki、menyukai、mencintai、menghadiri、mengikuti、menyertai、memiliki、mengetahui）；同一词根的 -kan / -i 对比（mendatangkan / mendatangi，menjauhkan / menjauhi，menempatkan / menempati）；不能同时带两个后缀；写作：5 句各含一个 -kan 或 -i 动词。
- 词表：-i 动词 25、-kan / -i 对比组 10（各作一条）、名词 25、整句 5、补充至 80。
- 课内阅读：日记。

### ms-11 · di- 被动与 oleh（第 11 周，12-14 至 12-20）

- 讲解：第三人称施事的被动：di- + 词根（不带 meN-）+ oleh + 施事（Buku itu dibaca oleh Ali.）；施事可省；di- 与 -kan / -i 组合（diberikan、dikunjungi）；di- 前缀与介词 di 的区别（连写 / 分写）；被动在新闻与说明文里的频率；主动转被动练习。写作：5 句被动句。
- 词表：di- 形式 20（front 为 di- 形，note 写主动形）、新闻与公共事务名词 25、动词 15、连词 5、整句 5、补充至 80。
- 课内阅读：简单新闻。

### ms-12 · 被动第二式、ter-；A1 复习与自测（第 12 周，12-21 至 12-27）

- 讲解：第一、二人称施事的被动：宾语 + 施事代词 + 光杆动词（Buku itu saya baca. / Surat ini awak tulis?），助动词与否定的位置（Buku itu belum saya baca.）；ter- 三义：意外（terjatuh、tertidur、terlupa）、能力（terangkat、terbaca）、状态（terbuka、tertutup），最高级义留到 ms-16；复习第 5–11 周的词缀总表；自测：限时写作 80 词，阅读复述。
- 词表 40 条：ter- 形式 12、复习用总结词与学习用语 15、整句 8（`phrase`，含被动第二式例句）、补充至 40。
- 课内阅读：说明文（介绍马来语词缀或一件日常事物），本课阅读注明可作自测材料。
