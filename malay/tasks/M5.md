# 任务 M5：马来语 ms-17 至 ms-20（第 17–20 周）与阅读线 ms-r31 至 ms-r38

先完整读 `malay/tasks/00-common.md`，再读本文件。前提：M4 已合并。dailyTime 与讲解开头同 M4。每课 80 条；6 + 4 题；课内阅读 230–300 词 16–20 句。

## 课程

### ms-17 · 复合句 1：原因、结果、转折、让步、条件（第 17 周，2027 年 01-25 至 01-31）

- 讲解：kerana / sebab / oleh sebab（因为）、jadi / oleh itu / maka（所以）、tetapi / namun / walau bagaimanapun（但是）、walaupun / meskipun / sungguhpun（虽然）、jika / kalau / sekiranya / andai（如果）；从句位置与逗号；书面语里 kerana 与 sebab 的分工。写作：5 句各用一个连接词。
- 词表：连词 15、生活事件名词 25、动词 20、副词 10、整句 5、补充至 80。
- 课内阅读：日记。

### ms-18 · 复合句 2：目的、时间关系、程度（第 18 周，2027 年 02-01 至 02-07）

- 讲解：supaya / agar（为了）、untuk + 动词；sehingga / hingga（直到、以致）；sementara / semasa / ketika / sewaktu（当……时）、sebelum / selepas / setelah / sesudah、apabila / bila（当、一旦）、sejak；begitu … sehingga（如此……以致）。写作：100 词记一天，用到 5 个连接词。
- 词表：连词与时间关系词 15、一天与旅行的名词 25、动词 20、副词 10、整句 5、补充至 80。
- 课内阅读：短故事。

### ms-19 · yang 从句、bahawa 宾语从句、间接引语（第 19 周，2027 年 02-08 至 02-14）

- 讲解：yang 从句作主语和宾语的修饰（orang yang membaca buku itu、buku yang saya beli）；yang 在被动第二式里的语序；bahawa 引导宾语从句（Dia berkata bahawa …）；间接引语：berkata、memberitahu、bertanya sama ada …、menyuruh + 动词；iaitu（即）。写作：5 句转述别人说的话。
- 词表：言语动词 15、连词与引导词 8、名词 30、动词 15、整句 7（`phrase`）、补充至 80。
- 课内阅读：对话（转述）。

### ms-20 · 语气词与语体；口语缩略只识别（第 20 周，2027 年 02-15 至 02-21）

- 讲解：-lah（软化、强调、Dialah yang …）、-kah、pun（也、即使，及 … pun 结构）、juga、sahaja、pula、lagi、memang、sudah tentu；正式与非正式：saya / aku，anda / awak / kamu / kau，beliau；口语缩略 tak、nak、dah、je、ni、tu、mana、macam mana、ke apa（只识别，卡片加 `口语;phrase` 只出识别卡）；书面语与网络文本的差别。写作：5 句用语气词。
- 词表：语气词与副词 15、口语代词与缩略 15（`口语;phrase`）、社交与网络名词 20、动词 15、整句 5、补充至 80。
- 课内阅读：短信或便条（含口语），注明「口语文本，写作时不用」。
