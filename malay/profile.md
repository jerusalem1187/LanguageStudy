## 迁移分析

### 能从英语借

- **英语借词**：大量现代生活词汇直接从英语借入并按马来语拼写规则改写，认得规律就不用背：bas（bus）、teksi（taxi）、komputer、telefon、universiti、stesen（station）、hospital、restoran、hotel、muzik、filem、kamera、bank、polis（police）、doktor、tiket、kad、kaunter、sains、matematik、ekonomi、klinik、farmasi、televisyen、radio、internet、lif（lift）、aiskrim、coklat、biskut、kek、jus、projek、program、sistem、teknologi、mesin、motosikal、lori。规律：c → k（komputer），-tion → -si（stesen 例外）、-ty → -ti（universiti）、双辅音简化（bas）、词尾 e 去掉（filem 加 e 拆辅音簇）。
- **语法术语**：affix（词缀）、prefix / suffix、classifier（量词）、reduplication（重叠）、passive（被动）读英文语法书时直接认。

### 能从西语借

马来语从葡萄牙语借了一批词，和西语同源，学过西语的人一眼能认：meja（mesa 桌子）、sekolah（escuela 学校）、gereja（iglesia 教堂）、keju（queso 奶酪）、mentega（manteca 黄油）、garpu（葡 garfo 叉子）、bendera（bandera 旗）、tuala（toalla 毛巾）、almari（armario 柜子）、kereta（carreta，马来语指汽车）、bola（bola 球）、pesta（fiesta 节庆）、roda（rueda 轮子）、limau（limón 柑橘）、kemeja（camisa 衬衫）、sabun（jabón 肥皂）、tenda（tienda，马来语指帐篷）、minggu（domingo，马来语指「星期、周」）、nanas（ananás 菠萝）、palsu（falso 假的）、bangku（banco 长凳）。

### 能从中文借

- **闽南语借词**：饮食和市井词汇不少来自闽南话，会中文的人看拼写猜得出：teh（茶）、mi（面）、kuih（粿）、tauhu（豆腐）、tauge（豆芽）、bihun（米粉）、kicap（鲑汁，酱油）、lobak（萝卜）、cawan（茶碗，杯子）、teko（茶壶）、loteng（楼顶，阁楼）、sampan（舢板）、kongsi（公司，马来语指「分享、合伙」）、angpau（红包）、tanglung（灯笼）、pau（包子）。
- **语法结构**：这是从中文借得最多的一门。马来语和中文一样没有冠词、没有性数、没有格、动词不按人称和时态变化；时间和体用副词和助词表达（sudah 已经、akan 将、sedang 正在、belum 还没、pernah 曾经）；名词加量词（seorang guru 一位老师，sebuah buku 一本书）；主谓宾语序；「是」在很多句子里可以不出现（Saya pelajar. 我学生。）；形容词可以直接作谓语（Rumah itu besar. 那房子大。）。这些在西语和俄语里要专门建立的概念，马来语一个都不用。

### 要专门建立的概念

| 概念 | 阶段 | 说明 |
|---|---|---|
| 修饰语后置 | 第 1–3 周 | 形容词、指示词、所有者都放在名词后面：rumah besar（大房子）、buku ini（这本书）、buku saya（我的书）。中文和英语都是前置，前几周写句子时最容易写反。 |
| 量词系统 | 第 3 周 | 和中文的量词很像，但词不同：orang（人）、ekor（动物）、buah（一般物件、水果、建筑、车、书）、batang（长条物）、helai（薄片、衣物）、biji（小圆物）。数字 + 量词 + 名词的顺序和中文相同。 |
| 词缀 | 第 5 周起持续到 B1 | 马来语语法的主线。同一个词根加不同词缀得到不同词类和用法：ajar（教）→ belajar（学）、mengajar（教）、pelajar（学生）、pengajar（教师）、pelajaran（课）、pengajaran（教学）。meN- 前缀按词根首字母变形（me- / mem- / men- / meng- / meny- / menge-），并且 p、t、k、s 开头的词根首字母脱落：pakai → memakai，tulis → menulis，kira → mengira，sapu → menyapu。词典按词根排，查带词缀的词要先还原词根。 |
| 两种被动 | 第 11–12 周 | 第三人称施事用 di-：Buku itu dibaca oleh Ali.（那本书被阿里读了。）第一、二人称施事不用 di-，把宾语提前、动词用光杆形式：Buku itu saya baca.（那本书我读了。）书面语里第二种很常见，读的时候要认出主语在动词前面这个结构。 |
| kami 和 kita | 第 1 周 | 两个「我们」：kami 不包括听话人，kita 包括。中文英文都不分。 |
| 语气词 | 第 20 周 | -lah、-kah、pun、juga、sahaja、pula 这些小词改变语气和信息焦点，没有直接的中文对应，靠例句记。 |

| semalam | 印尼语 semalam（昨晚） | 昨天 |
| kelmarin | 印尼语 kemarin（昨天） | 前天 |
| budak | 印尼语 budak（奴隶） | 小孩 |
| percuma | 印尼语 percuma（白费的） | 免费的 |
| bisa | 印尼语 bisa（能） | 毒 |
| kereta | 印尼语 kereta（火车） | 汽车 |
| pejabat | 印尼语 pejabat（官员） | 办公室 |
| senang | 印尼语 senang（高兴） | 容易 |
| ahli | 印尼语 ahli（专家） | 成员 |
| jemput | 印尼语 jemput（接人） | 邀请 |

## 难点地图

| 难点 | 阶段 | 说明 |
|---|---|---|
| e 的两种读音不在拼写里区分 | 第 1 周 | 字母 e 代表两个音（弱的 ə 和清楚的 e），拼写一样。只学读写时不影响拼写，但会影响默读时给词配的读音；遇到就在 note 里标一下，不专门练。 |
| 修饰语后置 | 第 1–4 周 | 见上表。每周写作任务写完先检查名词短语的顺序。 |
| meN- 的变形规则 | 第 6 周起 | 五条鼻音同化规则加首字母脱落，是拼写卡的主要错误来源。做法：每个 meN- 动词的卡片 note 里写词根和规则编号，写作时按表查。 |
| -kan 与 -i 的分工 | 第 9–10 周 | 两个后缀都能把动词变及物，-kan 偏使役和受益（membesarkan 使变大，membelikan 替某人买），-i 偏处所和方向（mengunjungi 拜访某地，menyukai 喜欢某物）。不靠规则背，靠高频动词整词记。 |
| 被动第二式 | 第 12 周 | 见「要专门建立的概念」。阅读里出现频率高，写作里探索段不要求主动用。 |
| 名词化词缀 | 第 13–15 周 | peN-、-an、peN-an、per-an、ke-an 各管一类意思，同一词根可以派生四五个名词。学法：以词根为单位做「词族表」，每课的 note 里列出同族已学词。 |
| 书面语与口语的距离 | 第 20 周 | 口语和网络文本里大量缩略（tak = tidak，nak = hendak，dah = sudah，je = sahaja）和口语代词（aku、kau）。只学读写阶段以标准书面语为主，口语形式只做识别卡。 |
| 马来西亚与印尼拼写 | A1 起 | 查词典和搜索时会混进印尼语资料。规则：kerana / karena、boleh、wang / uang、pejabat / kantor、universiti / universitas、stesen / stasiun、kesihatan / kesehatan、bahawa / bahwa、iaitu / yaitu。卡片只用马来西亚拼写。 |

## 文字与拼写要点

拼写和读音基本一一对应，没有变音符号，所以马来语的文字阶段只要一周。

- **字母**：26 个拉丁字母，和英语一样。f、q、v、x、z 几乎只出现在借词里。
- **双字母**：ng、ny、kh、sy、gh 各表示一个音，拼写时不能拆：bunga（花）、nyanyi（唱）、khabar（消息）、syarikat（公司）、ghaib（隐匿的）。ng 和 n + g 的区别：tangan（手）里是 ng；tanggal（脱落）里是 ng + g。
- **元音**：a、e、i、o、u 五个字母；e 有两个读音但写法相同。双元音 ai、au、oi：pandai（聪明）、pulau（岛）、amboi（感叹词）。
- **音节结构**：多数词根两个音节，结构是 (C)V(C)：ma-kan、bu-ku、ru-mah。认出音节有助于记拼写和找词根。
- **词缀拼写**：前缀和词根连写（membaca），不加连字符；重叠用连字符（buku-buku）；ke- 加数词表示序数或总数（kedua 第二 / 两个都）。ber- 遇到 r 开头的词根写成 be-（renang → berenang），遇到 kerja 写 bekerja，遇到 ajar 写 belajar。
- **大小写与标点**：句首、专名、语言名和国名大写（bahasa Melayu 里 Melayu 大写，bahasa 小写）；星期和月份大写（Isnin、Januari）；标点和英语相同。
- **数字**：小数点用点，千位用逗号，和英语相同。
- **星期与月份的马来西亚写法**：Isnin、Selasa、Rabu、Khamis、Jumaat、Sabtu、Ahad；Januari、Februari、Mac、April、Mei、Jun、Julai、Ogos、September、Oktober、November、Disember。印尼语写法不同（Senin、Kamis、Jumat、Minggu；Maret、Agustus）。
- **键盘输入**：不需要任何特殊设置，英文键盘直接打。

每日练习（第 1 周）：从课程页词表里抄 10 个词和 3 句，第二天看中文默写，对照原文标出拼错的双字母和词缀。每天 5 分钟。第 2 周起并入日常课的阅读时间。

### 考试锚点

马来语没有像 DELE 或 ТРКИ 那样和 CEFR 对齐、面向外国学习者的通用考试。可参照的外部标准：马来西亚中学的 SPM 马来语科（母语者水平，只作上限参照）；Dewan Bahasa dan Pustaka 和马来亚大学语言学院面向外国人的马来语能力测试或课程分级（名称和是否开放报名用前核实）。阶段出口以本仓库自己的自测为准：阅读复述和限时写作。

## 以后加听说时

当前不用。加听说时先补一个发音周，再接入下面的资源。

- **发音要点**：e 的两个读音（pepet ə 和 taling e）；词尾 k 是喉塞音（tidak、budak）；r 是舌尖颤音或闪音；ng 在词首也出现（ngeri）；重音轻，通常落在倒数第二音节；双元音 ai、au 在口语里常单化。
- **系统课**：Teach Yourself《Complete Malay》的音频；Language Transfer 没有马来语，Pimsleur 有印尼语无马来语（不要拿印尼语代替）。
- **可理解输入**：马来西亚新闻电视（Astro Awani、TV3）的 YouTube 频道；马来语儿童动画（Upin & Ipin，口语强、语速快，适合 A2 后）。
- **工具**：Forvo（真人发音，马来语条目比印尼语少）；italki、Preply（马来语教师较少，筛选时看是否为马来西亚人）。

## 探索段目标（起始值）

第 9 周结束时（2026-12-06）随西语、俄语一起复盘。达不到不等于失败，用来看方法和投入是否合适。

- 卡片约 1000–1300 张（ms-01 至 ms-09，约 720 条词条），已掌握不少于三分之一。
- 不查词典能读懂 100 词左右、只用已学词的短文（阅读复述 ≥ 3）。
- 能用 ber- 和 meN- 动词、时间标记（sudah / akan / sedang）写 5 句昨天和明天做什么，名词短语语序不错。
- 认出 meN- 五种变形并能还原词根查词典。
- 累计投入约 18–20 小时（每周 2.0–2.5 小时）。
