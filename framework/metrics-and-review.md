# 记录与复盘

## 时间记录：log/time.csv

一行一条，学完就记。字段：

| 字段 | 取值 | 说明 |
|---|---|---|
| date | YYYY-MM-DD | |
| lang | es / ru / …（ISO 639-1 代码） | 加新语言时用新代码 |
| activity | srs / input / system / output / review | 固定枚举，见下 |
| minutes | 整数 | |
| material | 短文本，不含逗号 | 用的材料，如 `现西 L3`、`分级读物 p12`、`东方俄语 L2` |
| note | 可空，不含逗号 | |

activity 枚举：

- `srs`：卡片复习与加卡（srs/index.html）
- `input`：读当前级别的材料
- `system`：教材、语法专项
- `output`：抄写、默写、写句子、写短文、批改
- `review`：周志、月度复盘、整理错题本

汇总命令（在 LanguageStudy 目录下运行）。

按语言累计小时：

```bash
awk -F, 'NR>1 {h[$2]+=$4} END {for (l in h) printf "%s\t%.1f h\n", l, h[l]/60}' log/time.csv
```

某一周按语言和活动汇总（改 from 和 to 两个日期）：

```bash
awk -F, -v from=2026-09-14 -v to=2026-09-20 'NR>1 && $1>=from && $1<=to {m[$2" "$3]+=$4} END {for (k in m) printf "%s\t%d min\n", k, m[k]}' log/time.csv | sort
```

## 周志：log/YYYY-Www.md

每周日 15 分钟，从 `framework/templates/weekly-log.md` 复制。文件名用 ISO 周，如 `2026-W38.md`。

内容：本周小时（从汇总命令抄）、做了什么、卡住的点、下周调整。

## 错题本：<语言代码>/errors.md

写作练习和批改暴露的错误记进去。字段见模板。同一类错误复现 3 次以上，做成拼写卡，并在错题本的「状态」列标「已做卡」。

## 月度检查点

每月最后一个周日做，替代那周的周志，从 `framework/templates/monthly-review.md` 复制。探索期的三个检查点：2026-10-11、11-08、12-06（第三个同时是探索期复盘）。

每门语言的自测：

1. **阅读复述**：选 1 段没读过的当前级别文本（西语：分级读物约 300 词；俄语：教材课文或双语文本约 100 词）。不查词典读一遍，用中文写要点。再查词或对照译文核对，给「读懂比例」打 1–5。
2. **限时写作**：15 分钟，不查词典，写本月的一件事。西语 100 词，俄语探索期 50 词。写完用词典和语法书自己改，错误记进 errors.md，记下错误数。
3. **数据**：SRS 页面的统计：总卡数、已掌握数（间隔 ≥ 21 天）、本月正确率。time.csv 的本月小时和累计小时。
4. **主观**：兴趣 1–5；下个月还想不想继续。

### 起始目标值

复盘时对照。达不到不等于失败，用来判断时间投入和方法是否合适：

- 西语：约 800–1000 张卡；不查词典能读懂 A1 分级读物的大意；能用现在时和过去时写 5 句。
- 俄语（实际学了 8 周）：约 400–500 张卡；字母认得全，手写和打字都行；认得主格、宾格、前置格；能用 5 句写自我介绍。

### 决定矩阵

| 情况 | 后续 |
|---|---|
| 两门都想继续 | 进入建设期，时间分配俄语 60 / 西语 40（俄语更难） |
| 只想继续一门 | 那门进入建设期拿全部时间；另一门进维持模式（见 weekly-cycle.md），不归零 |
| 都不想继续 | 换语言。用模板起新目录，已学的两门进维持模式或停止 |
| 想加第三门 | 不加。等其中一门到 B1 |
| 是否加听说 | 同时决定。加的话先补发音周，见各语言 profile 的「以后加听说时」 |

「想不想继续」以主观兴趣分和上个月实际投入小时为准：兴趣分 ≥ 3，且本月投入不低于计划的 60%，算「想继续」。
